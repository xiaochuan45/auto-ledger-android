本轮版本用于验证“云端编译 → 手机下载 → 安装启动”的交付流程。

- 应用：**本地账本·预览**，`io.github.xiaochuan45.autoledger.preview`
- 版本：`0.1.0-preview`（1），最低 Android 8.0 / API 26
- 功能：账单、统计和设置的基础预览界面；暂无账单保存、付款识别或数据导入
- 安装文件：下方 Assets 的 **`auto-ledger-preview.apk`**
- 审计证据：同一版本的 `auto-ledger-preview.apk.sha256`、`permissions-audit.md`

此发布由工作流在 APK 编译、Android lint、实际安装包审计和 Android 15 模拟器启动/导航测试全部成功后创建。具体结果以本发布附带的 Actions 记录为准。模拟器通过不表示已在一加 Ace 5 上实测；微信、支付宝及各消费平台的识别场景均未在本阶段验证。

使用临时 Debug 签名，跨构建覆盖安装不作保证；正式签名和升级保留数据尚未验证。当前是独立、无账单功能的预览应用，不能用于保存真实账目。

安装时按系统提示，仅为下载浏览器或文件管理器临时允许安装未知应用。无需授予通知读取、无障碍等权限。启动后检查账单、统计和设置页面，反馈 Android/ColorOS 版本及安装、启动结果即可。

APK 审计要求无网络及系统敏感权限、仅导出启动 Activity、关闭备份，并排除 Android 12+ 云备份与设备迁移的全部数据域。若 AndroidX 引入应用自身的 signature 级内部权限，会在审计报告中明确列出。

下一阶段才开始自动识别小样：本地读取明确付款成功信息、金额识别、去重、保存与记录查看，并提供权限设置和真机场景测试步骤。
