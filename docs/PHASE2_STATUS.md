- 安装并进入设置，开启自动记账总开关和微信、支付宝两个渠道开关；通知和无障碍都曾显示已授权、已连接。
- 用户清理后台后在拼多多使用微信支付，并跳转微信付款页；该次付款未形成记录，记为一次真机漏记失败。
- 返回账本时，通知显示已授权、未连接，无障碍显示已授权、已连接；系统通知使用权仍开启。
- 本轮未收集付款金额、付款页面类名或文字格式。通知断连和漏记是同轮观察，尚不能把断连、页面适配或其他因素确定为唯一原因。具体系统和支付应用版本可在后续兼容排查时补充，不要求为此重新消费。

本次漏记可手动补记。恢复连接不会回扫旧通知，也不会补抓这次已丢失的交易；不用重复支付来测试恢复。

`0.2.1-prototype` 的修复代码已实现：在总开关、渠道和通知授权允许的前提下，使用 Android 官方 `requestRebind` 请求通知服务重连；30 秒节流，每个断开周期自动尝试一次。设置页根据实际状态流自动反映真实连接回调，并分开提供“打开通知权限设置”和“尝试恢复通知监听”操作。请求已发出不等于服务已连接。

此修复不新增权限，不扩大付款应用或页面白名单，不回扫历史通知，不补抓旧交易，也不能绕过系统强行停止或厂商后台限制。源码和准确固定签名 APK 的 CI 均成功；发布说明见 [RELEASE_0.2.1.md](RELEASE_0.2.1.md)，后续真机反馈：已安装、服务显示连接，但再次拼多多微信付款仍漏记。

## 实现范围

- 微信、支付宝必要付款页面与非会话交易通知的本地规则识别；采集默认关闭，可控制渠道和系统权限。
- 明确成功及实付金额才确认；金额、状态或交易身份有歧义进入待核对。余额、收入、失败、待支付及不完整信息不冒充消费。
- 平台、支付渠道、分类独立存储；未知信息留空；时间标注为支付、识别或用户填写。
- Room 本地存储，强渠道交易号及来源收据持久去重；弱相似只提示待核对，不强行合并。支持显式保留另一笔或合并重复、手动补记、编辑、删除撤销。
- 统计仅提供已确认消费总额；退款、转账、充值、提现本阶段保持待核对，不计入消费。完整周期统计、分类规则、退款关联、导入导出和加密备份属于后续阶段。
- 状态页区分授权与连接，显示不含原文的本次进程诊断计数，提供恢复入口。权限或状态正常不代表所有后台场景可捕获。

## 自动记账触发与后台运行

采集默认关闭。用户在设置中一次开启自动记账总开关及所需的微信/支付宝渠道开关，并按引导授予系统通知使用权、启用无障碍服务。两类来源由相应系统服务处理：新的可读交易通知触发通知监听，受支持付款页面事件触发无障碍识别；不要求账单应用界面常开，也不循环读屏。

离开账本界面、按 Home 或切到付款应用，与清理最近任务、清理后台或系统“强行停止”不同。相关服务需要保持授权并获准后台运行；清理操作在不同厂商系统上的效果不同，强行停止、撤销权限或省电限制可能中断服务，应用不能保证绕过。状态页提供授权、连接检查和恢复入口，不代表已在所有系统验证后台常驻或付款捕获。

`0.2.1` 在权限仍开启且服务未连接时，可点击“尝试恢复通知监听”，以实际连接回调和状态为准。允许后台活动、在最近任务中锁定等选项可按品牌实际情况选择，但不保证解决断连。历史 `0.2.0` 可在系统中关闭再开启本应用的通知使用权，返回账本点刷新后检查。

没有可读付款页面和交易通知的付款无法自动捕获，尤其不能仅凭付款页面承诺后台扣费覆盖。当前可手动补记；账单文件导入属于后续功能。实际捕获范围以具体手机、系统及支付应用版本的测试结果为准。

## 兼容与隐私边界

目标是通用 Android 8.0 及以上，不绑定手机品牌。`0.2.0` 源码测试矩阵在 API 26/35 模拟器各 27 项通过；实际签名 release APK 另通过 API 35 测试。不能将模拟器推广为厂商系统或所有支付版本通过。用户已确认 `0.2.0` 安装、授权入口和连接状态，一次拼多多微信付款漏记；其他付款场景与长期后台稳定性仍待实测，`0.2.1` 已安装并显示服务连接，拼多多微信付款再次漏记；其他细项仍待测。

仅两个付款应用进入过滤。为避免聊天冒充支付通知，会拒绝 conversation、MessagingStyle、people 等会话消息；这也可能漏掉微信实际使用会话形式发送的官方支付通知。无障碍原生路径使用精确付款 Activity 清单；通用聊天、Launcher 和小程序不读取。当前另有指定微信网页的有限栏目检查及主动一次读取，结果仍待核对，详见本文最新版本。类名、页面结构及通知格式需真实手机继续适配。

超过字符、片段或节点上限、读取不完整的输入整体丢弃，不用截断后剩下的“成功”字样猜测交易。没有交易号及付款时间的页面通常进入待核对。缺少共同交易号的相似来源不承诺完全自动关联；连续同额真实付款仍保留可独立确认。

应用不申请联网、存储或前台服务权限。两项采集服务分别受系统 BIND 权限保护；系统通知使用权和无障碍需要用户主动开启。仅必要结构化字段与不可逆收据哈希进入数据库，不记录原始屏幕、通知、聊天或异常全文。自动云备份与设备迁移数据域均排除。
